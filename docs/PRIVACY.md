# Linking The World Temp HA 隐私说明

**Linking The World Temp HA** 是本地 Home Assistant 集成。它通过局域网 TCP/9000
连接 MC7021；不需要摩根云、MQTT 或外部遥测服务。最低支持 Home Assistant
`2026.9.0`。

## 本地配置与运行数据

Home Assistant 配置条目保存连接所需的主机地址、端口、本地主机账号和密码、协议客户端
ID 及科技系统总控 MAC。此类数据由 Home Assistant 管理，用于建立本地会话；集成不会将
它发送到项目维护者、云服务或分析平台。

为提供设备状态，运行时会处理总控运行与节能控制状态、控制器温湿度、PM2.5、CO2、原始故障
码、面板协议标识、房间信息、温湿度、目标温度、可用性和命令确认。已发现面板的稳定
标识、房间标识、发现/最近报告时间、可用性和已观察
缺席时间会被保存在 Home Assistant 的集成存储中，以便重启后恢复发现结果和安全处理长期
未上报面板。

## 诊断导出

通过 Home Assistant 下载的集成诊断只包含排障所需的匿名化、有限数据：

- 非机密运行选项，例如端口和命令超时；
- 连接阶段、失败类别、协议/控制状态和队列长度；
- 总控运行状态、环境测量值和主机上报的原始故障码；
- 有界的连接、解码、测量与命令计数，以及命令确认延迟摘要；
- 总控与整体状态年龄，以及最近 30 条控制的时间戳、匿名目标、操作类型、排队/确认耗时、
  发送次数、查询次数和结果；这些控制记录只在内存中保留，集成重载或重启后清空；
- 最近 8 条异常协议帧的长度关系、协议头/结束符状态、帧类型、操作码、序列号和恢复结果；
- 匿名面板标签（如 `panel_01`）、匿名房间标签（如 `room_01`）、可用性、报告年龄和
  已观察缺席时间。

诊断不会导出主机地址、用户名、密码、客户端 ID、总控或面板 MAC、真实房间名、密钥、
令牌、原始协议帧或完整配置条目。失败历史保留的是经过脱敏的短消息和受限数量的时间戳，
不会保留帧内容。

匿名标签仅在单个导出中保持关系可读，并不表示真实设备或房间名称。

## 日志

生产日志记录简短的连接生命周期、失败类别、重试、命令确认和恢复信息，便于判断问题处于
网络、握手、认证、协议还是状态流阶段。包括 debug 模式在内，协议日志仅记录帧类型、操作码、
序列号和帧体长度等安全元数据；不输出原始 TCP/YASHCP 帧，也不应包含密码、主机地址、
客户端 ID、真实 MAC、房间名、密钥或令牌。

不要为了提交问题而启用或复制原始协议报文。原始帧可能包含家庭设备标识或未公开的厂商
字段，并且通常不是重现连接问题所必需的材料。

## 安全地请求支持

1. 下载集成诊断，并确认文件中仅有匿名 `panel_XX` / `room_XX` 标签。
2. 收集复现前后尽可能短的一段日志，说明 Home Assistant 版本、集成版本、连接阶段、
   失败类别和是否出现 Repair。
3. 发送前人工删除截图、日志或文字中的地址、账号、密码、MAC、客户端 ID、房间名、
   密钥、令牌和任何原始十六进制协议数据。
4. 仅通过你信任的私密支持渠道共享诊断。公开 issue 应只包含已核对的脱敏摘要。

如果诊断或日志似乎包含敏感数据，请不要上传；先在本地删除该材料并报告脱敏缺陷。更多
恢复说明见 [TROUBLESHOOTING.md](TROUBLESHOOTING.md)。

## 账户与本地网络

建议 App 使用 `Test` 账号、Home Assistant 使用 `admin` 账号，以降低主机会话竞争风险。
这不是访问控制替代方案：应继续保护 Home Assistant、MC7021 局域网和备份，并且不要将
TCP/9000 暴露到公网。

## 维护范围

本隐私说明描述 HACS 原生集成 `1.2.9`。本仓库不再发布独立 MQTT Bridge，也不会处理
该历史实现的配置、日志或运行数据。
