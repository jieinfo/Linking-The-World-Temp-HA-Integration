# Linking The World Temp HA

本项目用于将 **Linking The World** 小区的六恒科技系统接入 Home Assistant，
通过家庭局域网连接 MC7021 主机，并在 Home Assistant 中提供科技系统总控、
房间温控面板、环境状态和故障诊断。

> [!IMPORTANT]
> 这是社区项目，不是摩根官方工具。当前协议与实机验证范围以 MC7021 和已交付的六恒
> 科技系统为主；未知主机型号、固件或状态包布局可能不兼容。首次接入未知环境时，建议
> 先关闭控制权限，只观察状态是否稳定上报。

当前稳定版本：`1.4.1`。最低支持 Home Assistant `2026.9.0`。

## 快速开始

1. 确认 Home Assistant 版本不低于 `2026.9.0`，并已安装 HACS。
2. 在 HACS 的“自定义存储库”中添加：

   ```text
   https://github.com/jieinfo/Linking-The-World-Temp-HA-Integration
   ```

   类别选择“集成”。HACS 自定义存储库必须使用上面的官方 GitHub 地址。
3. 安装 **Linking The World Temp HA**，然后重启 Home Assistant。
4. 打开“设置 -> 设备与服务 -> 添加集成”，搜索 **Linking The World Temp HA**。
5. 输入 MC7021 的局域网地址、本地主机账号和密码。端口通常保持 `9000`。
6. 配置成功后会立即创建“科技系统总控”；房间面板会在收到有效上报后自动发现。

建议手机 App 使用 `Test` 账号，Home Assistant 使用 `admin` 账号。不要让两端复用同一
账号，否则 MC7021 可能因会话竞争而断开其中一个客户端。

## 支持的设备与功能

| 范围 | 支持内容 |
| --- | --- |
| 科技系统总控 | 总开关、制冷/制热/通风/除湿模式、居家/离家场景、冬季加湿、节能控制 |
| 房间温控面板 | 自动发现、开关、16-28 °C 整数设温、当前温度与湿度 |
| 环境状态 | 温度、湿度、PM2.5、CO2 |
| 故障诊断 | 主机故障状态、新风滤网故障状态、独立原始码传感器和 Home Assistant Repairs |
| 运行诊断 | 连接阶段、失败类别、协议状态、控制权限、命令确认状态和面板数量 |
| 平台协作 | Home Assistant 自动化、原生 Climate 卡片和 HomeKit Bridge |

温度、湿度、PM2.5 和 CO2 均来自安装在新风管道、回风口或同类位置的独立传感器，
经 Mo-Bus 上报并由主机汇总；这些数值不是 MC7021 机身测量数据。

## 配置集成

首次配置需要以下信息：

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| 主机地址 | 无 | MC7021 的局域网 IP 或本地域名 |
| 主机端口 | `9000` | MC7021 本地协议端口 |
| 本地主机账号 | `admin` | 建议与手机 App 使用不同账号 |
| 本地主机密码 | 无 | 对应账号的本地密码 |
| 协议客户端 ID | 内置默认值 | 没有明确协议依据时不要修改 |
| 科技系统总控 MAC | 内置默认值 | 没有明确设备依据时不要修改 |

集成会先按规范化后的主机地址和端口阻止重复配置，再实际连接主机并验证握手与登录。
明确的密码拒绝会显示“主机拒绝登录”；网络超时、握手失败和登录超时会保留各自的错误
类别，不会被误判为密码错误。

保存后可在“设置 -> 设备与服务 -> Linking The World Temp HA -> 配置”修改运行选项：

| 选项 | 默认值 | 用途 |
| --- | --- | --- |
| 允许从 HA 控制设备 | 开启 | 关闭后以只读方式运行 |
| 控制命令最小间隔 | `0.5` 秒 | 限制连续写入速度 |
| 命令确认超时 | `8` 秒 | 等待主机状态确认的时间 |
| 主机静默重连时间 | `300` 秒 | 整体状态中断的重连阈值；总控单独静默时先查询再重连 |
| 面板无上报离线时间 | `900` 秒 | `0` 表示关闭短期离线检测 |

## 设备与实体

### 科技系统总控

- **控制**：总开关、运行模式、场景、冬季加湿和节能控制。
- **状态**：温度、湿度、PM2.5 和 CO2。
- **诊断**：主机连接、连接阶段、连接失败类别、协议兼容、协议验证状态、控制权限、
  最近控制命令状态和已发现面板数量。
- **故障**：主机故障状态和新风滤网故障状态。两个实体均使用 Home Assistant 的“问题”类型。
- **故障诊断**：主机故障原始码和新风滤网故障原始码。

### 房间温控面板

每块有效上报的面板会成为独立设备，并提供：

- 一个 Climate 实体，用于开关和调整目标温度；
- 当前温度和当前湿度；
- 面向自动化的滤波温度和滤波湿度传感器。

面板记录会跨重启保留。HA 或主机重连后，保存的面板会先显示不可用，收到该面板的新
上报后逐个恢复，不会因为主机重连而把已经离线的面板误判为在线。

## 控制规则

- 可直接选择制冷、制热、通风或除湿模式。科技系统总控已开启时，集成会等待主机依次
  确认关闭总控、切换模式和恢复开启；总控原本关闭时，切换后继续保持关闭。
- 模式切换过程中如果关闭或模式命令没有得到确认，集成会停止事务且不盲目重新开启，
  避免在错误模式下运行。
- 冬季加湿只在制热模式下可用。
- 房间面板跟随总控模式：制冷时显示“制冷/关闭”，制热时显示“制热/关闭”。
- 总控关闭后，房间面板仍可按总控保留的制冷或制热模式独立开启，且不会联动开启总控。
- 通风或除湿模式下，房间面板继续显示测量值，但保持关闭且不能启用制冷/制热。
- 房间目标温度范围为 16-28 °C，步进为 1 °C。
- 高频连续调温只保留最新目标值，不会把每个中间温度依次发送给主机。
- 总控写入共享串行命令队列，并以主机主动状态上报作为确认；必要时才合并查询状态。
- TCP 写入成功不等于设备已经执行，只有匹配的主机状态回报才算确认成功。

集成分别监测整体状态流和总控状态。即使房间温湿度仍在上报，总控超过静默阈值不更新时
也会查询一次状态；经过至少 10 秒（或更长的命令确认超时）仍无总控回报，才标记会话离线
并重连。TCP 写入最多等待 8 秒，连接关闭清理最多等待 3 秒，防止异常网络长期阻塞恢复。

## 故障提醒与 Repairs

“主机故障状态”和“新风滤网故障状态”在原始码为 `0` 时显示正常，收到非零值时显示
检测到问题。
两个独立诊断传感器在 `0` 时显示“无故障”，非零时显示具体整数；没有可靠厂商资料时
不会猜测具体含义。尚未收到有效总控状态或主机断开时，四个实体均显示不可用。

相同故障码持续上报不会反复写日志，故障码变化会更新现有 Repair，恢复为 `0` 后自动
清除。故障提醒只用于诊断，不会阻断总控或房间面板控制。

Home Assistant 2026.9 用户可在安全面板编辑器中，将这两个实体加入“活动警报”，并按家庭
需要设为“警报”或“警告”；也可以将它们加入收藏。

集成还会针对以下情况创建 Repair：

- 连续三次登录超时；
- 主机协议不兼容；
- 连续三条最终控制命令未获确认；
- 房间面板累计 30 天“已观察缺席”。

面板长期未上报 Repair 只提供手动清理入口，不会自动删除设备。完整判断逻辑和处理步骤见
[故障排查指南](docs/TROUBLESHOOTING.md)。

## HomeKit

可通过 Home Assistant 的 HomeKit Bridge 将总开关、运行模式和房间 Climate 实体桥接到
Apple 家庭。HomeKit 会把运行模式显示为包含制冷、制热、通风和除湿四个互斥按钮的组合；
当前模式保持点亮，直接点击另一个模式即可切换，不需要先手动关闭当前模式。

总控开启时，模式按钮会触发经过主机状态确认的“关闭 -> 切换 -> 恢复开启”事务。Home
Assistant、HomeKit、日志簿及基于总控状态的自动化可能短暂观察到真实的关闭状态；房间面板
仍受总控模式和主机状态确认约束。

## 升级与卸载

在 HACS 中安装新版本并按提示重启 Home Assistant。正常升级不会改变集成 domain、配置
条目、设备标识、实体 unique ID、历史数据或自动化引用。

卸载前先在“设置 -> 设备与服务”删除集成配置项，再从 HACS 卸载。删除配置项会停止后台
任务，并清理该配置项拥有的 Repairs 与 Home Assistant 本地面板发现历史；它不会修改
MC7021 内部配置。普通重载、重启和版本升级会保留这些本地记录。

## 隐私与诊断

本集成只与局域网内的 MC7021 通讯，不发送项目遥测。Home Assistant 配置条目会保存连接
所需的地址和凭据；下载诊断时会排除地址、账号、密码、客户端 ID、真实 MAC、房间名、
密钥、令牌和原始协议帧。

诊断还提供总控与整体状态年龄，以及最近 30 条匿名控制时间线，用于区分排队、合并替换、
发送失败和确认超时。记录仅在内存中保留，重启或重新加载集成后清空。

提交问题前，请阅读[隐私说明](docs/PRIVACY.md)，只提供脱敏诊断和复现时间附近的短日志。
不要公开主机密码、家庭公网入口或原始 TCP/YASHCP 十六进制报文。
